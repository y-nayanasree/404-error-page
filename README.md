
# 404 Error Page

A friendly and responsive custom 404 error page built using HTML5 and CSS3.

## Features

- Large and clear 404 error message
- Custom CSS illustration
- Friendly error description
- Back to Homepage button
- Responsive centered layout
- Hover and focus effects
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS gradients and shapes
